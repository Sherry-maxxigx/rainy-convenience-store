## 交付方式

- 网站上传版：根目录 `index.html`、`app.js` 和完整 `assets/`，同时包含源码与文档。
- 离线版：项目文件夹同级的 `rainy-convenience-store-offline.html`。
- 压缩备份：同级 `rainy-convenience-store-github.zip`，解压后再将文件夹内容上传 GitHub。
- 依赖、离线构建中间文件和测试输出不放入上传目录；可按 README 的命令重新生成。

这里验证的是本地模拟的 GitHub Pages 子路径。项目尚未上传或发布到 GitHub，实际网站地址需要完成上传与 Pages 设置后获得。
